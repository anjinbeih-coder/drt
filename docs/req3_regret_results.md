## checkpoint 来源与一致性说明

- 6 个 checkpoint 为本轮重训产物(req3p10ck_*,save_model=True,配置与实验 2/2b 完全一致)。
- 重训净利润:DSPO 1987.26/1956.26/2003.75,SPO+ 1964.70/1940.36/2016.27(配对差 −22.6/−15.9/+12.5,平局)。
- **一致性门槛触发与裁决**:除 DSPO_3456 外,重训净利润与实验 2/2b 同 seed 数值不一致。根因:HGS 求解器为
  墙钟时限(1.1s/1.5s),CPU 负载不同(6 进程并行 vs 原单进程)导致同种子路线分岔;numpy/torch 种子均按 run 设置,
  非种子问题。裁决:6 个 checkpoint 为同配置合法模型样本,遗憾对比(全部模型评同一份共享集)不受影响;
  放弃与实验 2/2b run 的同一性声明。**副产品发现:同 seed 同配置的运行级噪声可达净利润 ±50~90,
  与全部已观测 SPO+ vs DSPO 净利润差同量级——净利润对方法分辨无效,遗憾指标是正确标尺。**

## 验收判读(spec §1.4 三分支)

1. **负遗憾诊断:通过**。训练后的模型负遗憾占比 0~0.26%(阈值 5%),oracle 近似误差未掩盖信号
   (对照:3-episode 欠训练冒烟模型为 7.3%)。
2. **DSPO 遗憾水平**:相对遗憾 1.58%(0.707/客户,oracle 上界 44.665/客户),高于"无空间"阈值 1% →
   分支 (a) 不成立,但**可改进空间本身很小**:即便遗憾降为 0,每 episode(~85 客户)上限收益约 60,
   与运行级噪声同量级。
3. **SPO+(α=0.7) 是否降低遗憾:分支 (b) 不成立,落在分支 (c)**。(配对差按表格约定 DSPO−SPO+,正值表示 SPO+ 遗憾更低)逐 seed 配对(n=1529/对):
   - seed 2345:+0.0041(即 DSPO 遗憾更高,SPO+ 更低,p=3.6e-40);seed 3456:+0.0031(SPO+ 更低,p=5.0e-17)——
     **方向正确、统计显著,但幅度仅为遗憾的 ~0.5%,经济上可忽略**(有效梯度权重 ~6% 的预期后果);
   - seed 1234:−0.200(SPO+ 更差 28%,p=2.9e-110),且 MSE 96.8 vs 64.6——该 seed 上 SPO+ 项
     损害了预测质量,"MSE↑ 而遗憾↓"的决策导向签名**未出现**;
   - POOLED 均值 −0.064 由 seed 1234 主导,中位数 ≈0。
4. **结论**:在 RC 合成快速档,(i) Huber 基线已把可改进遗憾压到 1.58%,天花板很低;(ii) α=0.7 的 SPO+
   在 2/3 seed 上有微小但显著的正向作用,在 1/3 seed 上显著劣化;结合 α≥1.5 的角点崩塌(实验 2),
   **本场景不存在"既稳定又有实质增益"的 α 窗口**。SPO+ 的主战场应转向可改进遗憾更大的场景
   (预测更难/异质性更强,如燕郊真实数据),或先做稳定化改造(镜像截断)再扩大有效 α。
