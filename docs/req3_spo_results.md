## 验收标准逐条判定(对照规格 §1)

1. **SPO+ 生效硬证据 — PASS**:重跑 3/3 个 run 零失败行,权重按重锚定后的调度从首个有标签 episode 起爬升到 0.7,数据填充证据齐全。**这是修复 `_get_terminal_label_route` 与 ĉ 单位对齐之后,SPO+ 首次以论文定义的目标真正参与训练**(此前历史上所有 DSPO_plus_SPO 结果均为纯 Huber;本轮首跑虽已"生效"但目标失真,见版本说明)。
2. **净利润排序 — FAIL(如实报告)**:实际 DSPO 1937.9 > SPO 1932.8,差 5.1(σ≈23 的 22%),实质是**平局**。逐 seed:SPO 在 1234 赢 +58.2、2345 输 −23.3、3456 输 −50.4。
3. **退出率 — PASS(且为两轮一致的正向信号)**:SPO 5.27%±0.27 **低于** DSPO 5.69%±0.12(修复前一轮为 5.34%,方向一致),与手稿叙事相符(DRPO 降低退出率)。
4. **消融 — 一半成立**:管线一致性 **PASS 且达到最强形式**——SPO-ablation 三个 seed 与 DSPO 打印精度内一致(1905.60/1950.66/1957.58,委托父类的预言精确应验),对比中不存在任何管线混淆;SPO+ 增益 **FAIL**:−5.1,统计上无法区分。
5. **审计成文 — PASS**:`docs/req3_spo_alignment_audit.md`(safety_margin 表述已随终审修复更正)。

## 机制观察(SPO+ 在净利润之外做了什么)

- **稳健信号只有一个:退出率更低**(修复前 5.34、修复后 5.27,均低于 DSPO 的 5.69)——SPO+ 训练下的定价把更少客户推向外部选项,两轮一致;
- **总成本与 DSPO 统计上相当**(2063.0±35.8 vs 2055.4±24.1)。首轮出现的"成本均值更低且方差缩到 1/3.5"在修复后**未复现**——那是 ĉ 单位失真(CNN 项被压小约 75 倍,定价近乎退化为纯插入成本驱动)带来的伪稳定,不是 SPO+ 的真实效果,特此更正;
- **净定价收入相当**(收费−折扣 ≈ 75–86/episode,两组同量级);
- 结论:在快速档(500 ep,SPO+ 有效梯度权重仅约 6%,见下)下,论文定义的 SPO+ 对净利润呈**中性**,唯一可复现的增益是留客。

## 局限性与后续建议

- **快速档训练量(论文 0.5%)**:SPO+ 实际生效仅约 373 个 episode(500 − 初始阶段 112 − 重锚定后的 warmup 5 + rampup 10),
  在此规模下"净利润平局 + 更低退出率"是符合预期的中间结果;
- **有效 α 远小于名义值**:实现中 SPO+ 损失除以 (K+1)≈12(审计文档偏差项 1),名义 α=0.7 的有效梯度权重
  约为 Huber 的 0.7/12≈6%。若要给 SPO+ 更大话语权,可用新暴露的 `--spo_loss_weight` 提高名义值
  (等效于抵消归一化),这是现成的下一步实验旋钮,本轮未做(规格约定最小消融);
- 建议的坐实路径(按成本从低到高):① 提高 `--spo_loss_weight`(如 3.0≈有效 25%)重跑 SPO 组(约 1.7h);
  ② 深度档 5000 ep(约 5.5h/组);③ 两者结合。任一步都不改代码,只改参数。
